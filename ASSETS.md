# Visual assets

Original project work and Camilo’s portrait are supplied assets. The `optimized` directory contains compressed WebP copies; originals remain available as source material.

`src/assets/images/fynaq-hero.jpg` is a screenshot of the public Fynaq homepage at https://www.fynaq.com/en, captured September 18, 2026 with its cookie banner dismissed. Confidential case studies intentionally contain no public product screenshots.

Imagine uses original procedural characters, pond geometry and animation built with Three.js in `src/app/views/imagine/pond`. No external models, textures or reference photographs are loaded. `src/assets/images/imagine/frog-story.svg` is an original vector illustration for the WebGL fallback.

The previous architecture, Severance and Journey reference assets were removed when Imagine became the frog story.

The flower and frog marks in `src/app/components/living-mark` are original SVG drawings, replacing the previous star motif throughout the site.
